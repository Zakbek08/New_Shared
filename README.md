# WalletWise

**Which card should you use?** Tell WalletWise what you are about to buy and it works out
which card in your wallet earns you the most on that purchase.

**Try it: https://zakbek08.github.io/New_Shared/** — nothing to install. See
[PREVIEW.md](PREVIEW.md) for how to run it locally instead.

---

## The whole app, in four steps

1. **Sign in** — a name and an email address. No password, because there is no account.
2. **Choose your cards** — search the catalog for the cards you actually hold.
3. **Start a purchase** — where, how much, what kind, how you are paying.
4. **Get the answer** — one card, the figure it earns, and why it beat the alternative.

Open it a second time and it goes straight to step 3, with your name and cards already
there.

## What makes the numbers trustworthy

**Every figure is computed, never written down.** Reward values come out of a pure
TypeScript engine (`src/domain/rewards/`) applied to rule records — the same input always
produces the same answer. No part of any reward figure is generated by a language model.
The engine is forbidden a clock, a network call and a random number, and
`src/domain/purity.test.ts` enforces that by reading its source.

**Every rate is dated and sourced.** 22 cards from 8 issuers, each transcribed by hand
from that issuer's own product page. Every card shows the date it was read and links the
page, because a rate with no date is a claim about today that nobody has checked. The app
tells you to confirm with your bank before relying on a figure.

**Nothing is guessed.** If a card is not in the catalog, the app says so instead of
offering the nearest match. If a bonus needs activating with your issuer, it is not
counted until you confirm you have — recommending an unactivated 5% bonus would have you
pay with a card earning 1%.

**Points are valued at a stated floor.** 1¢ per point, said out loud on the answer screen.
It is an assumption, not a rate, and it is pessimistic on purpose: a points card that wins
at 1¢ wins at any higher valuation.

**No incentive to mislead you.** WalletWise earns nothing from any card it recommends.
There are no referral links, and a test asserts the source URLs carry no referral
parameters.

## What it will never do

| Never                                               | Why                                              |
| --------------------------------------------------- | ------------------------------------------------ |
| Take a payment, or move money                       | It is an information tool                        |
| Ask for a card number, CVV, PIN or banking password | There is no legitimate use for them here         |
| Sign in to your bank, or import transactions        | That means holding banking credentials. Refused. |
| Fetch or scrape an issuer's website                 | Fragile, hostile, and unnecessary                |
| Take a referral fee for a recommendation            | It would make the recommendation worthless       |

---

## Privacy

There is no server. Your name, email and card list are saved on your own device, and the
recommendation is computed there too. Nothing about you is uploaded, because there is
nowhere for it to go.

The trade-off, stated plainly: clearing your browser data or reinstalling the app loses
your details, because there is no backup.

## For developers

```bash
npm install
npm run preview:web    # dev server, opens on localhost:8081
npm run verify         # format check + lint + typecheck + tests. Run before committing.
```

| Path                  | What lives there                                              |
| --------------------- | ------------------------------------------------------------- |
| `app/`                | The six route files. Screens compose features; no logic.      |
| `src/data/`           | The card catalog: real products, dated and sourced.           |
| `src/domain/`         | Pure logic. No React, no I/O, no clock.                       |
| `src/features/local/` | On-device storage, and the bridge from a wallet to an answer. |
| `src/components/`     | The design system.                                            |

Architecture in [ARCHITECTURE.md](ARCHITECTURE.md), the testing matrix in
[TESTING.md](TESTING.md), the working agreement in [CLAUDE.md](CLAUDE.md).

1,301 tests across 36 suites, no skips. CI additionally drives the built bundle through
all four steps in a real browser — the only check that can answer "can a person open this
and get an answer?"

## Disclaimer

WalletWise provides financial **information**, not financial advice. Reward rates,
categories and caps are set by card issuers and change without notice. Your bank decides
which category a purchase is coded under, and it can differ from what you would expect.
Always confirm terms with your issuer before relying on them.
